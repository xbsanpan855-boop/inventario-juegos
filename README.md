# Inventario de juegos

### Descripción

Esta aplicación es un gestor de biblioteca personal de videojuegos. Su propósito es permitir al usuario llevar un registro organizado de su colección, controlando detalles como las horas dedicadas, la plataforma de juego y el estado de progreso (jugando, pendiente o completado).

### Tecnologías

- **React + TypeScript** (Vite)
- **Firebase Firestore** (Base de datos en la nube)
- **CSS Inline** (Diseño personalizado)
- **Vercel** (Despliegue)
